# agent

The Kubernetes Security Remediation Agent demo is maintained on the [`kube-remediation-demo`](https://github.com/tuanngocfun/agent/tree/kube-remediation-demo) branch. This initial branch contains only the repository bootstrap; the demo is developed and executed separately.

## VGU interview rehearsal

The prepared teaching and research package is in [vgu-rehearsal](vgu-rehearsal/START_HERE.md). It includes worked notebooks with saved outputs, editable lecture/research decks, PDFs, full scripts, separate student exercises, reproducible CPU setup, Spec Kit requirements and verification evidence.

For rendered documents, equations and notebook outputs, clone this branch, enter `vgu-rehearsal`, run `python3 -m http.server 8766 --bind 127.0.0.1`, and open `http://127.0.0.1:8766/site/index.html`. See [browser/setup instructions](vgu-rehearsal/BROWSER_README.md).

Student TODOs and personal rehearsal/submission actions remain explicitly unfinished. The private source-evidence/application records and installed environments are not bundled.
