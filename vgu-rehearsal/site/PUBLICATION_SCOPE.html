Repository export scope

This package shares teaching and research rehearsal materials: worked notebooks, learner exercises, model code/tests, timed scripts, slide files, rendered reading pages and portable setup/check scripts. Public scholarly references remain attributed. Proposed experiments are labelled as plans, not completed results.

The export excludes private application records, appointment/contact instructions, private supporting-document filenames, credentials, machine environments/caches and the original machine-specific audit. Personal-history claims must be supplied and confirmed by the presenter; this package does not establish them.

Exported checks describe only the bundled files. They can establish saved outputs, tested code behavior, slide/notes consistency and functioning local links. They do not certify the original private provenance audit, a fresh installation on every platform, actual presentation delivery, student comprehension or completed submission.

For a clean build, regenerate notebook outputs and derived slides/HTML from the exported sources. Keep paths relative or generated at setup time; avoid carrying host paths into saved output or reports. Inspect notebook metadata, slide notes/hyperlinks, PDF file-link annotations and rendered source downloads as well as visible text. Run the portable checks and review every intended upload file before publishing. Repository delivery is complete only after remote contents are read back; preparing this folder alone is not a delivery result.
