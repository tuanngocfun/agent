Rehearse the 30-minute lecture

Start at Present this lecture. Open the lecture PDF beside the timed script. The PowerPoint contains presenter notes. The 15-minute lecture Q&A is additional to the prepared 30 minutes.

Follow the sequence: motivation → tokens and embeddings → conditional probability → attention by hand → shapes and scaling → mask and target shift → generation → a student project. Use the student pathway and assessment handout to plan the next tutorial.

Inspect and run the worked notebooks

  1. 01 — Core attention worked: tokens, embeddings, numerical attention, distinct rectangular shapes, mask versus weights, target shift and loss. The worked attention output is approximately [1.3395, 1.3210].
  2. 02 — Training and generation worked: causal invariance, padding and empty-row policies, actual greedy 0.30 versus beam-width-3 0.40 search, EOS behavior and optional temperature sampling.
  3. 03 — Optional systems worked: RoPE, grouped-query attention, cache offsets and measured CPU timings. The measurements are not a general speed guarantee.
  4. 04 — Optional image-to-sequence worked: synthetic training, loss curves, matched greedy/beam/template evaluation and actual error analysis. Four known glyph templates illustrate mechanics, not real-document OCR generalization.

For code execution on Linux/WSL, have uv or Python 3.12 with venv support, then run from this directory:

bash scripts/setup_environment.sh
.venv/bin/python scripts/check_portable.py
bash scripts/open_jupyter.sh

The pinned environment targets Linux x86_64 CPU and Python 3.12. Setup downloads packages; matching wheels on other platforms are not guaranteed. Setup and launch register VGU rehearsal (CPU) using the current checkout location. The IDE workspace resolves .venv/bin/python relative to this folder. Exact dependencies are included; environments and caches are excluded.

check_portable.py inspects saved outputs, slide counts/notes and the packaged reference tests. It does not rerun notebooks or overwrite execution manifests. To recompute an example, open its notebook with the project kernel and run it explicitly. An unrerun saved output is not a new run.

The completed Tier 1 instructor notebook and Tier 2 instructor notebook provide additional worked implementations for preparation and questions. The historical Student-named notebook folder also contains completed references. Learners' independent tasks are now written in Student practice. Assign those prompts and ask for an explanation and a fresh implementation before sharing a worked reference.
