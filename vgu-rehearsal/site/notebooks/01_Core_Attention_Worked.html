1. Text → tokens → integer IDs → vectors

Our tiny whitespace vocabulary makes the mapping visible. Real tokenizers may split a word into multiple subword tokens. An integer ID indexes a learned embedding row; it is not a measure of word meaning or word order. IDs are local to this lab: BOS=4, I=0, love=1, AI=2, EOS=5, and PAD=6; another tokenizer may use different IDs. Ask: if we permute IDs and permute embedding rows consistently, must the model's represented input change?

2. A numerical attention calculation you can teach on paper

Queries describe what is being sought, keys describe what can match, and values supply the information to combine. With Q=[1,0]Q=[1,0]Q=[1,0], K=[[1,0],[0,1]]K=[[1,0],[0,1]]K=[[1,0],[0,1]], V=[[2,0],[0,4]]V=[[2,0],[0,4]]V=[[2,0],[0,4]], and dk=2d_k=2dk​=2:

s=QKT/dk=[1/2,0],a=softmax(s),z=aV.s=QK^T/\sqrt{d_k}=[1/\sqrt2,0],\quad a=\mathrm{softmax}(s),\quad z=aV.s=QKT/dk​​=[1/2​,0],a=softmax(s),z=aV.

Predict before running: the first key gets more weight, but its value does not simply replace the second value. Scaling controls score magnitude before softmax; it is not a probability normalization by itself.

4. A causal mask is not a probability matrix

An additive mask is 000 for permitted keys and −∞-\infty−∞ for forbidden keys. It is added to scores. Softmax over keys produces probabilities. Only those weights must sum to one for a row with a visible key. Below, all unmasked scores are zero so that the effect of the mask is isolated. Ask: why can the last position use all earlier input tokens, while the first uses only itself?

5. Shifted supervision and cross-entropy

For [BOS, I, love, AI, EOS], inputs are [BOS, I, love, AI] and labels are [I, love, AI, EOS]. The shift asks each position to predict its next token. The mask prevents access to future input positions. These are distinct operations.

For logits [ln⁡2,0,0][\ln2,0,0][ln2,0,0] and target index 2, probabilities are [1/2,1/4,1/4][1/2,1/4,1/4][1/2,1/4,1/4]. Thus loss −ln⁡(1/4)=ln⁡4-\ln(1/4)=\ln4−ln(1/4)=ln4 nats per token, and perplexity eln⁡4=4e^{\ln4}=4eln4=4. This is one artificial token, not a language model's reported benchmark perplexity.
