1. RoPE rotates paired features without changing their squared norm

Position changes the rotation angle applied to queries and keys. It does not rotate values here. The same frequency convention must be used for Q and K. A cache must start new positions at the correct offset.

2. Full, token-cached, and chunk-cached outputs must agree

With four query heads, compare one, two, and four KV heads. These correspond to shared, grouped, and per-head K/V. A cache stores prior K/V; it does not change which past tokens are visible. The full pass is an independent execution path. Chunk sizes 2, 3, and 4 exercise causal offsets beyond single-token decoding.

3. A declared CPU benchmark over three lengths

Compare producing one output per prefix in both paths. The uncached path recomputes the whole growing prefix; the cached path only computes the new token and retains earlier K/V. Both use the same model and predetermined inputs. Use one warm-up per path and five timed repetitions per length, with one CPU thread and no gradients. Report medians in milliseconds. Ratios describe this local toy kernel only and need not exceed one.

In [4]
benchmark_model=GQACausalAttention(d_model=32,n_heads=4,n_kv_heads=2).eval()
@torch.no_grad()
def cached_decode(x):
    cache=None;parts=[]
    for position in range(x.shape[1]):
        y,cache=benchmark_model(x[:,position:position+1],past_kv=cache,use_cache=True)
        parts.append(y)
    return torch.cat(parts,1)
@torch.no_grad()
def uncached_decode(x):
    return torch.cat([benchmark_model(x[:,:position+1])[:,-1:] for position in range(x.shape[1])],1)
timing_rows=[]
for length in (8,32,64):
    x=torch.randn(1,length,32)
    torch.testing.assert_close(cached_decode(x),uncached_decode(x),atol=2e-6,rtol=2e-6)
    row={'length':length,'warmup_per_path':1,'repetitions':5}
    for name,method in [('cached_ms',cached_decode),('uncached_ms',uncached_decode)]:
        method(x)
        durations=[]
        for _ in range(5):
            start=time.perf_counter();method(x);durations.append(1000*(time.perf_counter()-start))
        row[name]=statistics.median(durations)
    row['uncached_over_cached']=row['uncached_ms']/row['cached_ms']
    timing_rows.append(row)
    print(json.dumps(row))
(ROOT/'verification/cache_benchmark.json').write_text(json.dumps(timing_rows,indent=2)+'\n')

Reasoning to take forward

Explain why a wrong positional offset can invalidate a cache even when its shapes look correct. KV tensor bytes here exclude allocator overhead, model weights, activations, and intermediate repeated KV tensors. The reference GQA implementation repeats KV heads for clarity; it does not establish the performance of a fused serving kernel. A research extension varies sequence length, batch size, dtype, device, and KV-head count, checks output equivalence first, then reports timing distributions and total memory with the measurement policy stated.
