Rehearsal package quickstart

Open the start guide and the browser. Read the saved attention values in the first worked notebook without starting a kernel. The four worked notebooks contain computed outputs; the separate student exercises intentionally remain incomplete.

From the package root, follow the pinned setup instructions in the start guide, then run:

.venv/bin/python scripts/check_portable.py

This checks the bundled notebook results, slide counts/notes and reference tests. It does not rerun notebooks or reproduce the original local authoring audit. To recompute an example, open the notebook with the project kernel and explicitly run it.

The research claim ledger uses public scholarly sources and distinguishes proposals from results. Local authoring inputs, backups and professional records are outside this repository edition. The aggregate export checks are in verification/EXPORT_CHECKS.md.

Rehearse the lecture and research talk aloud with a timer. Human delivery, independent explanation, individual contributions and professional confirmations remain the presenter's own actions. No communication or submission is performed by these checks.
