## Harness architecture

The template starts one headless Pi process per task. The evaluator connects to `serve.py` over WebSocket and passes the task instruction and limits. Pi receives a general engineering prompt and calls the sponsored Claude Opus 5.5 endpoint. Its tool extension relays file operations, shell commands, and task MCP requests through `taskbridge.py` into the isolated task container. The harness returns its final message through the same WebSocket. The evaluator exports the deliverables and their hashes to the artifact manifest. ## Insight and failure analysis

All 29 manifest entries have status `ok`. Four received zero reward. The foundation-strategy and solar-witness-test-package entries exported no deliverable files. The foundation trace ended on a tool call. The last solar witness-test observation recorded an unauthenticated OpenProject request. The two data-hall MEP routing entries each exported the requested `solution.py` and still scored zero. Their final messages reported local IFC validation and documented assumptions about how to interpret parts of the design. Those cases call for two distinct checks before the harness signals completion. First verify that the files required by the prompt exist at the requested paths. Then open the outputs with the appropriate parser and validate the constraints the prompt makes testable. The individual failed routing grader checks remain unverified. A controlled ablation would compare the unchanged Pi prompt against a prompt with these completion checks, using the same model and replaying the same dev set before reporting a gain. ## Cross-model generalizability

The organizers benchmarked the Pi harness with multiple models on the same 29 development tasks, averaging each pairing over three runs. Pi scored **0.563 with Gemini 4 Neon**, **0.502 with Gemini 4 Hydrogen**, **0.474 with Claude Opus 5.5**, and **0.270 with Gemini 3.8 Flash**. Relative performance varied by discipline. Hydrogen led Opus on civil tasks, 0.665 to 0.590, while Opus led Hydrogen on mechanical tasks, 0.393 to 0.361. These results describe the organizers’ benchmark cohort. A controlled replay on the current entrant commit would hold the prompt, tool allowance, and grading fixed and report paired task outcomes. ## Efficiency and scaling

On the organizers’ leaderboard, Pi with Gemini 4 Hydrogen averaged **$3.82 per task** against **$13.29** for Claude Opus 5.5 while earning a higher mean reward. Gemini 4 Neon scored higher still at an estimated **$8.78 per task**. The score-versus-cost figure holds the harness family fixed and varies the model. The shifts in cost and score reflect model choice, reasoning settings, and usage together. The archived submission template has no reported dollar cost, and three of its 29 traces publish token totals. A controlled budget sweep remains pending. It would fix the model and prompt, vary the time or token budget, and track how often extra tool calls produce additional credit.
